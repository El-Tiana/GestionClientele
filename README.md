# GestionClientele

Application web de gestion de la clientèle développée en Symfony (PHP), dans le cadre d'un projet scolaire (solo).

## Fonctionnalités

- Gestion des fiches clients (création, modification, recherche par numéro)
- Gestion des doléances (réclamations clients)

## Stack

- **Back-end :** Symfony 5, PHP, Doctrine ORM
- **Front-end :** Twig

## Lancer le projet

\`\`\`bash
composer install
symfony server:start
\`\`\`
